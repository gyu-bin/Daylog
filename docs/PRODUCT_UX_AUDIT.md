# Daylog 제품 UX 점검 (2026-10-12)

기준 커밋 `7c45ae4`. 로컬 `main`에서 작업. SwiftData·CloudKit 모델과 저장 형식은 바꾸지 않았다.

검증 환경: macOS 검증 번들(`com.daylog.verify`, 표본 저장소, 백그라운드 조작), iPhone 17 Pro 시뮬레이터. 실제 설치된 앱·저장소·iCloud는 건드리지 않았다.

심각도: P0 데이터 손실·잘못된 기록 / P1 주요 기능 불가·상태 불일치 / P2 흐름 불편·레이아웃 / P3 시각·문구.

## 1. 확정 개선

### 휴가 대시보드 카드

문제(P1): 휴가를 등록해도 그날이 휴가가 아니면 카드가 계속 "휴가 설정 / 기간 추가"였다. 등록이 됐는지 카드에서 알 수 없었다.

고친 것: 카드가 `VacationStatus`(등록된 기간에서 계산만 하는 값)로 세 가지 모습이 된다.

| 상태 | 카드 |
|---|---|
| 휴가 없음(지난 휴가만 있는 경우 포함) | "휴가 설정" + 기간 추가 |
| 예정된 휴가 | "다음 휴가" + D-day 배지(내일 / D-3), 날짜·기간·메모 줄(누르면 수정), 휴가 관리 |
| 그날이 휴가 | 카드 전체가 옅은 휴가 색, "휴가 중" + "N일 남음 / 오늘까지" 배지, 기간 줄(수정·해제), 통계 제외·알림 쉼 안내, 그 뒤 다음 휴가 한 줄, 휴가 관리 |

- 여러 기간: 그날을 포함하는 기간이 먼저, 없으면 가장 가까운 예정 휴가.
- 겹치거나 하루도 안 띄고 이어진 기간은 한 구간으로 이어 남은 날을 센다(`continuousRun`). 하루라도 띄우면 따로다.
- 휴가가 끝난 다음 날에는 평소 카드로 돌아오고, 예정된 휴가가 있으면 그것을 보여 준다.
- 지난 날짜를 보고 있어도 D-day는 오늘 기준이다.
- 설정의 "휴가 관리" 줄도 같은 규칙으로 요약한다("휴가 중 · 10월 12일까지", "다음 10월 15일 · D-3", "예정 없음", "없음"). 캘린더의 날짜 상세도 같은 카드다.
- 기록·휴가 데이터는 바꾸지 않는다. 표시만 바꿨다.

검증: macOS 라이트·다크에서 예정(`product-ux/vacation-card-upcoming.jpg`) → 진행 중 + 다음 휴가(`vacation-card-active.jpg`, `vacation-card-active-dark.jpg`) → 수정 시트에서 해제 → 카드가 "다음 휴가 D-3"로, 달성률·주 평균이 복원. iPhone에서 기간 추가 → 저장 즉시 "다음 휴가 D-3"(`vacation-card-iphone.png`). 규칙은 `ProductUXTests` 7개.

### 캘린더 시작 요일

설정 → 캘린더 → "한 주의 시작"(월요일 / 일요일, 기본 월요일). 이 기기의 `UserDefaults`(`device.weekStart`)에만 저장한다. CloudKit·SwiftData 변경 없음.

적용: 월간 캘린더(대시보드·캘린더·iPhone 통계), 휴가 기간 달력, 식사 달력, 활동 히트맵(행 순서와 주 묶음). 요일 제목, 1일 앞의 빈칸, 주 묶음이 함께 바뀐다.

적용하지 않은 것: "최근 7일"과 통계의 집계 기간(오늘 기준 직전 N일 그대로), 루틴의 반복 요일 선택(평일·주말 묶음이 월요일 기준이라 그대로 둠).

검증: macOS에서 일요일로 바꾸자 캘린더·휴가 달력·히트맵이 즉시 바뀌고(`calendar-sunday-start.jpg`), 앱을 다시 켠 뒤에도 유지. 월말·연말·윤년·시간대 경계는 `ProductUXTests` 8개.

## 3. 발견한 문제

| 번호 | 심각도 | 문제 | 처리 |
|---|---|---|---|
| U-1 | P1 | 휴가를 등록해도 대시보드 카드가 바뀌지 않음 | 수정(1절) |
| U-2 | P2 | 캘린더에서 앞으로의 날짜를 누르면 휴가 등록 시트가 뜨는데, 눌러 보기 전에는 알 수 없음 | 달력 아래에 한 줄 안내 추가 |
| U-3 | P2 | macOS에서 창을 닫았다가 메뉴 막대로 다시 열면 첫 입력칸(아침 식사)이 전체 선택된 채 포커스를 받아, 바로 타이핑하면 적어 둔 내용이 덮어써짐. 실행 직후의 첫 창만 포커스를 풀고 있었음 | 새 창마다 처음 앞에 올 때 한 번씩 포커스를 풂(시트·메뉴 막대 창 제외) |
| U-4 | P3 | 휴가 중일 때 그다음 예정된 휴가를 볼 곳이 휴가 관리뿐 | 휴가 중 카드에 "다음 휴가 · … · D-n" 한 줄 |
| U-5 | P3 | 설정의 휴가 줄이 "N개 기간"만 보여 지금 상태를 알 수 없음 | 상태 요약으로 변경 |
| U-6 | P3 | 휴가인 날 "통계 제외" 안내가 휴가 카드·루틴 카드·달성 현황 카드에 세 번 나옴 | 남김. 휴가 카드를 숨길 수 있어 루틴 카드의 안내가 필요하다. 다음에 문구를 줄일 후보 |
| U-7 | P3 | 휴가 달력에서 범위가 주를 넘어갈 때 줄 끝의 띠가 둥글게 닫히지 않음 | 남김(읽는 데 지장 없음) |
| U-8 | P2 | 루틴의 반복 요일 선택은 시작 요일 설정을 따르지 않음(늘 월요일부터) | 남김. 평일·주말 빠른 선택과 한 묶음이라 순서만 바꾸면 어색하다. 요구가 있으면 함께 바꾼다 |

P0는 찾지 못했다.

## 4. 검증하지 못한 것

- U-3의 수정: 창을 닫고 메뉴 막대에서 다시 여는 조작은 배경에서 할 수 없어 실제로 해 보지 못했다. 코드 변경만 했다.
- 메뉴 막대 팝오버, 알림 도착, 위젯(이번에 조작하지 않음).
- iPad(이번 변경 화면은 다시 띄우지 않았다. 시트 틀은 디자인 2차에서 확인).
- 시작 요일 설정을 iPhone 설정 화면에서 바꾸는 조작(같은 코드, macOS에서만 눌러 봄).
- 날짜가 바뀌는 순간(자정)의 휴가 카드 전환: 계산 규칙은 테스트로, 실제 자정 넘김은 미검증.
- 좁은 macOS 창에서의 휴가 카드.
