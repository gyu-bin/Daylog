# 홈 헤더 및 피오 반응 — 2026-10-23

판정: PARTIAL. 새 헤더와 기존 리그를 재사용하는 반응 래퍼를 구현했다. 최종 UI 캡처/기기별 검증은 통합 QA 결과로 판정하며, DEBUG 독립 원화와 Release 기존 렌더러의 범위를 구분한다.

## 구현

- 좁은 홈 화면에서 `AppBrand.name`의 정확한 `RoutiMori`를 표시한다. 브랜드·피오·기존 편집/추가 버튼을 한 줄에 두고 날짜/인사말과 날짜 이동을 다음 줄에 정돈했다.
- 기본 피오 버튼64pt, 좁은 줄52pt 대안, 큰 글자/긴 날짜에서는 줄을 추가하는 대안을 사용한다. 피오가 사라지는 좁은 화면 대안은 없다. 캐릭터는 기존 보호용 캔버스 여유를 고려해1.25배 캔버스로 표시하며, 원화 비율은 바꾸지 않는다.
- 헤더/안내 간격 최대6pt, 안내/첫 콘텐츠 간격 최대12pt, 위 여백4pt로 줄였다. 개별 콘텐츠 카드 내부와 카드 순서/사용자 데이터는 유지한다. 기존 배경·타이포그래피·버튼 색상/모양을 재사용하며 장식 카드를 추가하지 않았다.
- iPhone 날짜 이동/오늘 버튼은44pt 높이와 이동 버튼44pt 너비를 확보한다. `DateNavigator`의 기본32pt 값은 유지하여 다른 넓은 화면 사용처의 기존 크기는 바뀌지 않는다.
- Mac/iPad 넓은 홈의 기존 행 구성/48pt 예약 높이는 유지하고 피오 표시만 같은 버튼 래퍼로 연결했다.

## 대기 및 터치 모션

새 `PioHeaderMotionStage`는 기존 `PioOverhaulRig`를 보유하는 래퍼다. 보호된 리그/원화 파일을 수정하거나 새 캐릭터 시스템을 만들지 않았다.

- 대기: 기존 idle의 눈 대체/몸통 숨쉬기를 그대로 사용한다. 기존 greet의 진짜 관절 트랙을 복사해6%로 낮추고17.3초의 부드러운 동작으로 재생한다. 자유 날개 최대 약1.08°, 크리스마스 선물/손 결합 최대0.12°다. 기존 greet의 자세 기울임도18%,27.6초로 낮춰 최대0.36°로 사용한다. 몸통 점프나 상하 이동을 대기 모션에 추가하지 않았다.
- 이는 별도 머리 레이어를 만든 것이 아니라 작은 전체 자세 기울임이다. 선물/베개/우산 등 소품에는 기존 리그가 정의한 결합/제한을 그대로 따른다.
- 터치: 인사2.8초 → 점프2.2초 → 응원3.8초를 순서대로 한 번씩 재생한다. 네이티브 트랙의 반복 횟수는0이며, 완료 Task가 대기 상태로 돌려놓는다.
- 이미 반응 중인 반복 터치는 새 반응을 겹쳐 실행하지 않는다. 이전 완료 콜백은 토큰이 달라지면 새 반응을 지울 수 없다.
- 기존 루틴 완료/건너뜀 반응도 기존 `SaessagiMood` 판정 규칙으로 유지한다. 완료는 기존 응원, 건너뜀은 기존 쉬기 모션4.2초를 사용하며 터치 순서를 소비하지 않는다.
- 상태는 피오 버튼 내부에만 있다. 프레임별 SwiftUI Timer/Task나 홈 전체를 갱신하는 모션 상태는 없다.

## 생명주기와 권한

화면 표시·네이티브 스크롤 가시성·scenePhase·Reduce Motion을 함께 확인한다. 공통 네이티브 호스트의 Mac 가림/최소화/orderOut 조건도 재사용한다. 화면 밖/백그라운드/Reduce Motion/의상 변경에서는 반응 Task와 CA 트랙을 정리하고 대기 자세로 돌아간다. 가시성 변경 콜백도 이전 값이면 무시한다.

권한은 기존 `PioAppearanceCoordinator`만 읽는다. 확인 중에는 캐릭터를 숨기고 버튼을 비활성화한다. 새 구매·소유권·착용 저장 경로나 구매 우회는 없다.

## DEBUG / Release 구분

- DEBUG `-PioOverhaulTrial`: 기존14종 분리 리그로 독립 눈/날개/지원 소품과 작은 대기 자세, 한 번의 터치 반응이 동작한다.
- Release 및 해당 플래그 없는 실행: 기존 `PioAppearanceView`/제작된 production 자원을 그대로 사용한다. 같은 컨트롤러가 기존에 지원되는 동작을 제한된 시간 재생하고 idle로 복귀한다. 기본은 기존 wave를 사용한다. 유료 합쳐진 원화가 wave를 지원하지 않으면 첫 인사 터치를 기존 bounce(짧은 통통 반응)로 명시적으로 연결하여 무반응 idle로 떨어지지 않게 했다. 독립 날개 인사로 표현하지 않는다. jump/celebration/rest도 기존 지원 동작을 사용한다.
- Release의 합쳐진 유료 원화에서 독립 눈/날개가 새로 지원된다고 주장하지 않는다. 새 DEBUG 리소스를 Release에서 활성화하지 않았다. 독립 대기 모션의 production 완료 판정은 PARTIAL이다.

## 접근성

피오는 최소44pt 이상인 하나의 Button이다. 접근성 레이블은 현재 의상과 ‘피오에게 인사하기’를 알리고, 진행 중 값과 Reduce Motion 힌트를 제공한다. 안쪽 장식적 이미지/네이티브 레이어는 중복 낭독하지 않는다. 브랜드는 헤더 trait을 유지한다. 큰 글자에는 날짜/버튼을 별도 줄로 배치하고 인사말의 줄 제한을 해제한다.

실제 VoiceOver 조작과 읽기 순서, 모든 Dynamic Type 단계의 시각적 승인은 자동화 소스 검사와 구분해 통합 QA에서 기록한다.
