# iCloud 첫 동기화 화면 리디자인: 세 장면 (2026-10-14)

시안(사용자 첨부 이미지 세 화면)을 기준으로, 공식 새싹이 레이어와 SwiftUI로 움직이는 화면을 만들었다.
검증은 검증용 Mac 앱(`com.daylog.verify`, 시험 저장소)과 Daylog 전용 시뮬레이터로만 했다. 실제 앱·기록·iCloud는 건드리지 않았다.

## 구조

- `SyncSceneMotion.swift`: 시각 t → 장면 한 순간(새싹이 자세, 구름, 카드, 체크, 별, 빗방울, 물음표). 계산만 하고 테스트한다.
- `SyncScene.swift`: 그 값대로 그린다. 새싹이는 공식 기본 모습의 레이어(몸·눈·입·잎·발)를 겹친 것(`SyncSaessagi`)이고,
  몸통 전체를 기울이고 띄우고 발밑 기준으로 조금 누를 뿐 원화를 비틀지 않는다. 수첩·기록 카드·구름·별·빗방울·새싹 장식은 SwiftUI 도형과 SF Symbols.
  `TimelineView`(1초 24번)로 그리며, 화면이 앞에 없거나 움직임 줄이기면 멈춘다.
- `FirstSyncView`: 실제 첫 동기화와 미리보기가 같이 쓴다. 상태 판정(`FirstSyncPolicy`), 기다림·재시도(`gate.tick/retry/finish`), 기록을 찾으면 바로 오늘 화면으로 가는 처리는 그대로다.
  바뀐 것은 그림·문구·단추 순서(다시 확인하기가 앞)뿐이다.

## 장면

| 장면 | 실제로 보이는 때 | 움직임 |
|---|---|---|
| 기록 받는 중 | 첫 동기화 대기(`waiting`), 기록을 찾았거나 없다고 본 직후의 한순간 | 구름 위아래·빛, 카드(체크·달력·루틴·통계)가 1.3초마다 한 장씩 머리 옆으로 살랑이며 내려와 수첩에 들어감(동시에 최대 2장), 들어올 때 새싹이가 끄덕이고 수첩이 들썩·반짝, 4.8초마다 쪽 넘김, 눈이 카드 쪽을 따라감, 깜빡임, 잎 살랑, 아래 점 세 개 |
| 준비 완료 | 미리보기에서만(실제로는 기록이 오는 순간 이 화면 없이 오늘 화면으로 간다) | 체크가 작게 나타나 부풀었다 통통 자리 잡음, 별 6개가 터지듯 나타났다 잔잔히 반짝, 새싹이가 수첩을 안고 두 번 뜀(두 번째가 더 높음, 착지 눌림·복원, 잎이 늦게 따라 흔들림, 눈을 가늘게), 그 뒤 잔잔하게 흔들고 숨 쉼 |
| 연결 문제 | 오래 걸림(`stalled(nil)`), 오류(`stalled(내용)`), iCloud 로그인 안 됨·제한(`unavailable`) | 회색 구름(순한 얼굴)이 좌우로 떠다니고 빗방울 셋이 번갈아 천천히 떨어짐, 새싹이가 구름을 올려다보며 왼쪽·오른쪽으로 갸웃, 잎이 축 처졌다 톡 돌아옴, 머리 위 물음표가 나타났다 사라짐 |

- 문구는 원인에 맞춘다. 로그인 안 됨은 "iCloud에 로그인되어 있지 않아요"와 로그인 안내(`mac-trouble-no-account.png`), 오래 걸림은 네트워크 확인 안내,
  오류는 "동기화 중에 문제가 생겼어요"와 오류 내용. 진행률·완료율·전송량은 어디에도 없다. 내려오는 카드는 받은 기록 수와 상관없는 그림이다.
- 미리보기: 위에 늘 "예시 화면 · 실제 iCloud 상태가 아니에요.", 고르기는 [기록 받는 중][준비 완료][연결 문제] 셋. 단추는 아무 일도 하지 않고 아래 안내 카드에 그렇게 적었다.
  고르면 배경·장면이 0.35~0.4초 동안 겹쳐 바뀐다. iPhone SE처럼 좁으면 [미리보기 종료]를 윗줄로 올려 안내가 한 줄에 들어간다.

## 검증

- Mac(시트 580×820): 라이트 세 장면, 다크 세 장면, 로그인 안 됨. 기록 받는 중은 0.45초 간격 연속 캡처로 카드가 내려와 수첩에 들어가는 것을 봤다(`mac-receiving-cards-sequence.png`).
  검증 앱을 뒤에서 띄워 창이 비활성이라 Mac 캡처의 단추는 회색으로 보인다(활성 창·iOS에서는 초록·파랑).
- iPhone 17 Pro Max: 세 장면 + 각 8초 영상(`iphone-*.mp4`, 준비 완료는 열리는 순간부터 녹화해 체크·별·두 번 점프가 들어 있다). 다크(연결 문제).
- iPhone SE(작은 화면): 세 장면, 다크(받는 중). 글·단추가 잘리지 않고, 아래 안내 카드는 스크롤로 보인다.
- iPad Pro 13: 세 장면, 다크(준비 완료).
- 움직임 줄이기(iPhone 시뮬레이터): 받는 중·연결 문제 모두 1.5초 간격 두 화면이 픽셀까지 같다(멈춘 한 순간). 확인 뒤 설정을 원래대로 돌렸다.
- CPU·메모리(Mac Debug 빌드, 장면을 띄운 동안 2초 간격 10번): 받는 중 평균 15.8%(최대 17.5%), 준비 완료 11.7%(13.0%), 연결 문제 12.4%(13.5%), 메모리 79~80MB.
  처음 30fps에서는 12~18%였다. `drawingGroup`으로 합쳐 그려 봤으나 CPU는 그대로이고 메모리만 143MB로 늘어 되돌렸다.
  Release 빌드는 디버그 실행 인자로 미리보기를 열 수 없어 재지 못했다(미검증). 화면을 닫거나 앱이 뒤로 가면 멈춘다.
- 테스트: SyncSceneTests 5개(카드 동시 2장 이하·네 종류·박자, 끄덕임·쪽 넘김·깜빡임, 체크와 두 번 점프 뒤 잔잔함, 빗방울·올려다보기·갸웃·물음표, 움직임 줄이기 정지 장면),
  SettingsPreviewTests(세 장면, 연결 문제 세 경우가 같은 장면, 실제 화면에서 준비 완료를 쓰지 않음) 포함 관련 51개 통과. Mac·iOS Debug 빌드 성공.

## 시안과 다른 점

- 새싹이: 시안은 수첩을 펼쳐 읽거나 앉아서 올려다보는 새 자세지만, 공식 원화에 그 자세가 없어 기본 모습(서 있는 자세, 두 손을 배 앞에 모음)에 수첩을 겹쳤다.
  손 위에 수첩이 놓여 들고 있는 것처럼 보이지만, 손가락이 수첩을 감싸지는 않는다. 연결 문제에서 앉은 자세 대신 서서 올려다본다. 표정은 기본 미소 하나라 시안의 "웃으며 눈 감은" 표정은 눈을 가늘게 뜨는 것으로 대신했다.
- 시안의 구름 아래 떠 있는 카드 여러 장, 바닥의 책 더미, 큰 풀숲은 줄였다(움직이는 카드와 겹치지 않게).
- 연결 문제의 구름 얼굴은 시안보다 순하게(작은 눈, 살짝 처진 입).

## 필요한 추가 원화(시안 품질에 더 가깝게 하려면)

1. 새싹이가 펼친 수첩을 두 손으로 잡고 읽는 모습(레이어: 몸, 수첩을 쥔 두 손, 눈 뜬/감은 눈).
2. 수첩을 꼭 안고 눈을 감고 활짝 웃는 모습(준비 완료).
3. 앉아서 위를 올려다보는 모습(연결 문제, 눈·잎 레이어 분리).
4. (선택) 시안 그림체의 초록 수첩 원화(펼친 것·덮은 것).

## 성능 검증과 최적화 (같은 날)

### 측정 방법
- 검증용 앱만 썼다. Debug는 `Tools/dev.sh build`, Release는 새 `Tools/dev.sh perf`(Release 최적화 그대로에 화면 검증용 실행 인자만 켠 빌드.
  임시 서명이라 강화된 런타임의 라이브러리 검증만 끔, 실행 속도와 무관). 순수 Release는 미리보기를 자동으로 열 방법이 없어 이렇게 했다.
- 장면을 띄우고 4초 뒤부터 `top` 2초 간격 10번(앱 프로세스). iCloud 요청 없음(시험 저장소, 검증 앱은 iCloud 권한이 없다).

### 원인
- Time Profiler(Release, 기록 받는 중, 8초 1,403표본): `TimelineView`가 1초 24번 미리보기 창 전체를 다시 배치(`NSHostingView.layout` 47%, 창 레이아웃 54%)하고
  SwiftUI 그래프를 갱신(`ViewGraph.updateOutputs` 32%)했다. 그라디언트·그림자도 매번 CPU로 다시 그렸다(`CA::Layer::display` 11%).
  즉 움직이는 몇 개의 조각 때문에 매 프레임 화면 전체를 다시 계산했다. 코드 최적화(Debug ↔ Release)로는 줄지 않았다.

### 바꾼 것
- 장면을 Core Animation 레이어로 옮겼다(`SyncSceneStage`). 조각은 처음에 한 번 그림으로 만들고(ImageRenderer), 움직임은 `SyncSceneMotion`을
  값마다 한 바퀴씩 키프레임으로 뽑아 무한 반복한다(`SyncSceneMotion.loop`, 되풀이가 정확한지 테스트). 그리는 일은 렌더 서버가 하고 앱은 쉰다.
- 점 세 개도 Core Animation으로 바꿨다.
- 숨쉬기와 잎 살랑임을 따로 떼어(주기가 다르다) 겹친 레이어로 곱하고 더한다. 모양은 같다.
- 버그 수정: 카드가 수첩에 닿을 때 끄덕임·반짝임이 가장 최근 카드가 아니라 가장 오래된 카드를 기준으로 계산되어 두 번째 카드부터 거의 보이지 않았다.
- 화면이 사라지면 애니메이션을 모두 내리고, 앞에 있지 않으면(scenePhase) 내렸다가 돌아오면 같은 시각 기준으로 이어서 건다.
