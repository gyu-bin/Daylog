# DEVICE-QA — 기기별 실제 화면 검증 (2026-10-24, 최신 소스 빌드)

모두 최신 작업 트리로 다시 빌드한 Debug 검증 앱(iOS 시뮬레이터, macOS `com.daylog.verify`)을 실행해 캡처하고 직접 확인했다.
시험 데이터는 격리 저장소(`uiqa`)에만 넣었다. PASS = 캡처로 확인, 결함 없음. NOT_TESTED = 실행하지 않음.

## 피오 홈 모션

- 홈 머리말 피오: 기본·AX5·다크 모두 표시 정상.
- 홈 동작 타이밍 테스트 8개 PASS(아래 RESULTS).
- 동작 길이와 연출은 바꾸지 않았다. 바꾼 것은 완료를 예약하는 방식뿐이다. 앱은 여전히 실제 시간으로 기다리고, 테스트만 예약을 직접 넘긴다.
