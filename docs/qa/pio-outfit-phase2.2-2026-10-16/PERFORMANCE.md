# Phase2.2 CPU·메모리 결과

판정: 통제한 DEBUG 파일럿의 단기 측정 완료. 성능 종합 PASS, 장시간 무누수, 실기기 배터리/FPS 보증은 하지 않는다.

같은 진단 화면에서 캐릭터 한 개를 220pt·밝은 배경으로 표시하고, 파일럿 이미지 55개를 미리 준비했습니다. Mac은 1040×900 창, iPhone은 전용 iPhone 17 / iOS 27 시뮬레이터를 사용했습니다. 실행 후 3초를 기다리고 1초 간격으로 프로세스 누적 CPU 시간과 RSS를 읽었습니다. 기본 측정은 20초, 전환 측정은 35초입니다.

측정 중 이 작업의 캡처·녹화는 없었습니다. 다만 기기는 다른 작업과 공유되어 전체 시스템 부하와 창의 가림 여부를 완전히 통제하지 못했습니다. CPU 100%는 코어 하나에 해당하며, GPU·WindowServer·렌더 서버 비용은 포함하지 않습니다.

## 해석과 제한

- iOS `flat-static`은 처음 세 구간에서 70.1 / 134.2 / 34.7%, 마지막 구간에서 23.8%를 기록했습니다. `layered-static`도 첫 구간이 37.5%였습니다. 3초 대기로 초기 작업을 충분히 제거하지 못했으므로, 이 두 행을 안정 상태의 애니메이션 비용과 직접 비교하거나 성능 개선으로 해석하지 않습니다. 반복 디코딩이나 리그 자체가 원인이라는 증거도 없습니다. 원인 확정에는 재현 시 CPU 프로파일이 필요합니다.
- iOS 동작 표본 평균은 0.000–0.098%, 전환은 1.016%였습니다. 0은 샘플 시간 해상도에서 증가가 없었다는 의미입니다. 정지 이미지의 초기 비용이 더 높았으므로, 동작 유무만으로 첫 실행 비용을 설명할 수 없습니다.
- Mac 기본·의상 idle/jump/flap 표본 평균은 0.049–0.393%, 30회 전환은 1.300%였습니다. 전환 후 configurations 31, hostUpdates 32, activeRigs 1, liveRigs 1, sourceLoads/cache 55를 확인했습니다. 눈 전용은 6개 트랙·몸통 0개, 양날개는 2개·몸통 0개, 걷기는 발 4개·몸통 0개였습니다. 점프는 몸통 1개, 착지는 몸통 2개입니다.
- 같은 Mac 프로세스(PID 80240)에서 30회 전환 후 뷰를 제거하자 liveRigs와 activeTracks가 0이 됐습니다. 이후 20.5초 평균 CPU는 0.049%, RSS는 43.94–74.48MiB였습니다. 별도 실제 스크롤 표본에서는 화면 밖에서 liveRigs 1 / activeTracks 0, 복귀 시 눈 트랙 6개 재개를 확인했습니다.
- iOS도 30회 전환 후 liveRigs 1, cache/sourceLoads 55, configurations 31이었습니다. RSS 첫값→끝값은 414.91→379.25MiB, 범위는 378.73–425.95MiB입니다. Mac 전환은 113.56→81.64MiB였습니다. 짧은 관찰에서 누적 증가 증거는 없었지만, RSS는 압축·회수의 영향을 받으므로 차이를 메모리 절감량으로 해석하지 않습니다.
- 캐시의 decodedBytes 56,144,964(약 53.54MiB)는 보관한 CGImage 버퍼 크기의 합계이며 앱 전체 메모리가 아닙니다. sourceLoads는 성공한 소스 조회 횟수이며 물리적인 PNG 디코더 호출 횟수가 아닙니다. 이미지 55개 선로딩은 비교 조건을 맞추기 위한 진단 화면 동작입니다.
- iPhone 실제 스크롤 검증은 Device Hub의 다른 시뮬레이터 전환과 겹쳐 최종 계측을 완료하지 못했습니다. Mac 스크롤과 두 플랫폼의 유효한 OS Reduce Motion 증거를 확보했지만, 이를 iPhone 스크롤 PASS로 확대하지 않습니다.

## 이전 16.08%와 비교

Phase 2.1의 PERFORMANCE.md 조사와 원시 증거를 재사용했습니다. 당시 16.08%는 화면 조건이 달랐으며 재현 조사에서도 확정된 병목이 없었습니다. 따라서 이번 결과를 ‘16.08%에서 0.05%로 최적화’라고 표현하지 않습니다. 이번 변경은 실제 분리 원화와 공유 Core Animation 리그의 추가이며, CPU 개선율은 미확정입니다.

추가 검증: 초기 작업 완료 후 동일 조건의 반복 측정, 실기기·Release·GPU·발열·장시간 메모리 프로파일. 원시 수치는 `performance-*.json`에 보존했습니다.
