# UI-AUDIT — RoutiMori 전 화면 시각 점검 (2026-10-24)

방법: 실제 앱(Debug 검증 빌드)을 시뮬레이터와 macOS 검증 앱(`com.daylog.verify`)으로 띄우고, 격리된 시험 저장소(`uiqa`, `uiqa-empty`, `uiqa-cloud`)에
같은 시험 데이터(그룹 2개, 긴 이름 1개, 시간·메모가 있는 항목, 완료 2개)를 넣은 뒤 화면을 캡처해 직접 확인했다.
글자 크기는 `xcrun simctl ui <기기> content_size`로 바꿨다. 결함을 고친 뒤에는 같은 조건으로 다시 캡처했다.
중간 캡처는 프로젝트 밖(`~/Library/Caches/DaylogQA.noindex/`)에서 만들어 검증 뒤 지웠고, 대표 증거만 `evidence/`에 줄인 크기로 남겼다.

심각도: P0 사용 불가·접근 불가·심한 잘림·겹침·크래시 / P1 과도한 줄바꿈·정렬·잘림·읽기 문제 / P2 미세한 간격·일관성.
