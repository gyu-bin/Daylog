# ACCESSIBILITY — 접근성 검증 범위 (2026-10-24)

자동 검증, 코드 점검, 실제 조작 검증을 나눠 적는다. 실제로 하지 않은 것은 NOT_TESTED로 둔다.

## Dynamic Type

| 항목 | 방법 | 결과 |
|---|---|---|
| 기본·AX5 실제 화면 | iPhone SE·iPhone 17·iPad에서 `content_size`를 바꿔 캡처하고 직접 확인 | 결함 19건 수정 후 PASS (UI-AUDIT 참조) |
| XXXL·AX1·AX3·AX5 폭 | 새 테스트 `DaylogStoreKitTests/UIDynamicTypeLayoutTests` 2개: 화면 조각 25종(iPhone 343·370pt)과 넓은 홈 조각 2종(343·480·700pt)이 글자 크기 5단계에서 제안 너비를 넘지 않는지 측정 | PASS. 되돌림 시험으로 넓은 홈 머리말 넘침을 실제로 잡는 것을 확인 |
| 금지 사항 | 화면 전체 `.dynamicTypeSize` 제한, 무차별 `minimumScaleFactor`, `.lineLimit(1)`로 숨기기, 음수 패딩을 쓰지 않음 | 지킴. 줄 제한은 오히려 큰 글자에서 풀었다 |

한계: 폭 측정은 "화면 밖으로 넘침"만 잡는다. 한 글자씩 꺾이는 줄바꿈, 겹침, 시각적 균형은 캡처 검수로 확인했다.
`FlowLayout`은 자기 너비를 늘 제안 너비 이하로 알리므로, 그 안의 넘침도 폭 측정으로는 잡히지 않는다.

## VoiceOver

| 항목 | 방법 | 결과 |
|---|---|---|
| 실제 VoiceOver 탐색(읽기 순서·말투) | — | NOT_TESTED: 시뮬레이터에 VoiceOver가 없고 실기기를 쓰지 않았다 |
| 자동 접근성 트리 검사 | 화면을 창에 띄워 접근성 트리를 도는 테스트를 만들었으나, 보조 기술이 켜져 있지 않은 테스트 환경에서는 SwiftUI가 트리를 만들지 않아 0개를 읽음 | NOT_TESTED. 의미 없는 통과가 되지 않게 테스트는 지웠다 |
| 아이콘만 있는 단추의 이름 | 코드 전수 점검(단추 라벨이 아이콘뿐인데 `accessibilityLabel`·`help`가 없는 곳) | 0곳 (검사에 걸린 1곳은 이름 있는 설정 줄) |
| 장식 아이콘 중복 읽기 | 줄 끝 꺾쇠 7곳 | 6곳 숨김. 홈 루틴 카드 그룹 머리말 1곳은 숨기면 크래시가 나서 되돌림(UI-AUDIT #7, R3) |
| 피오 | 홈 머리말 피오(`PioHeaderCompanion`)는 누를 수 있는 단추: 이름("기본 피오, 피오에게 인사하기"), 상태 값, 힌트(동작 줄이기면 "편안한 자세를 유지")가 있다. 그림 자체는 `accessibilityHidden` | 코드 확인 PASS, 실제 읽기 NOT_TESTED |

## 키보드 탐색 (Mac)

NOT_TESTED. 창을 직접 조작하는 권한 없이 배경 실행·캡처만 했다. 이번 수정은 Mac 배치를 바꾸지 않는다.

## 터치 영역

- 홈 날짜 이동·오늘 단추: 좁은 화면에서 44pt(기존 유지), 큰 글자 날짜 칸 분리 시 44pt로 맞춤.
- 요일 단추: 기본 32~40pt, 큰 글자에서 글자 높이에 맞춰 커진다(이전에는 고정 크기라 겹침).
