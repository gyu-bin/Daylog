# 피오의 한마디 (2026-10-25)

코드: `Daylog/Components/PioTalk.swift` (`PioLines`). 제목 줄 한 줄에 들어가도록 16자 이하로 쓴다(`PioTalkTests`가 확인).

## 배치
- **오늘 탭(iPhone·좁은 창):** 첫 줄에 피오와 늘 보이는 말풍선. 앱 이름 자리를 쓴다.
  - 피오를 누르면 다음 대사로 넘어간다.
  - 체크하면 2.5초 동안 반응 대사가 나온다.
- **다른 탭(루틴·식사·통계·캘린더·휴가·템플릿):** 제목 줄 오른쪽 끝에 작은 피오.
  - 탭을 열면 말풍선이 3초 뜬다. 누르면 다시 뜬다.
  - 아주 큰 글자에서는 말풍선을 띄우지 않는다.
- **설정:** 맨 위 카드에 지금 입은 옷, [옷장], "피오 말풍선 보기" 켜고 끄기를 둔다.
  - 끄면 오늘 탭은 "RoutiMori + 피오", 다른 탭은 피오만 보인다.
- iPad 넓은 오늘 화면과 Mac은 바꾸지 않았다.

## 오늘 탭 (첫 대사 → 누르면 다음)
| 상황 | 첫 대사 |
|---|---|
| 루틴 없음 | 첫 루틴, 같이 만들어요! |
| 아직 0개 · 아침(5–11시) | 좋은 아침! 하나씩 해요 |
| 아직 0개 · 낮(11–18시) | 첫 루틴 해 볼까요? |
| 아직 0개 · 저녁(18–23시) | 지금 해도 늦지 않아요 |
| 아직 0개 · 밤 | 내일 다시 해도 괜찮아요 |
| 1개 남음 | 하나만 더 하면 끝! |
| 절반 이상 | 절반 넘었어요! 좋아요 |
| 그 외 | N개 남았어요, 힘내요! |
| 다 끝냄 | 오늘 다 해냈어요! 최고! (연속 2일 이상: N일 연속이에요! 최고!) |
| 휴가인 날 | 오늘은 푹 쉬어요 |
| 지난 날짜를 볼 때 | 지난 기록을 보고 있어요 |
| 체크 직후(2.5초) | 좋아요! 하나 끝! |
| 건너뜀 직후(2.5초) | 괜찮아요, 쉬어 가요 |

- 누르면 넘어가는 대사: 의상 대사, 연속 2일 이상이면 "N일째 함께하고 있어요".
- 날·시간에 따라 의상 대사가 먼저 나오기도 한다(같은 시간에는 같은 대사).
