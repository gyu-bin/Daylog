## Daylog 1.5.3

**루틴을 더 유연하게 기록하고, 템플릿으로 시작하고, 큰 글자에서도 편하게.**

- **오늘 건너뛰기** — 못 하는 날에는 루틴을 건너뛸 수 있어요(⋯ 메뉴). 건너뛴 루틴은 따로 표시되고, 달성률에는 미달성으로 들어가요.
- **루틴별 최근 기록** — 통계에서 루틴마다 최근 수행 기록(완료·건너뛰기·기록 없음)을 한눈에 볼 수 있어요.
- **루틴 템플릿** — 공식 템플릿 11개를 미리 보고 필요한 것만 추가해요. 기존 루틴과 기록은 바뀌지 않아요.
- **템플릿 파일 공유** — 내 루틴 구성을 파일로 만들어 주고받을 수 있어요. 체크·식사·휴가 같은 기록은 파일에 들어가지 않아요.
- **오늘 화면 꾸미기** — 텍스트 카드, 섹션 제목, 구분선을 넣고 상단 배경을 정할 수 있어요.
- **사이드바 색** — 메뉴마다 색이 생겨 구분하기 쉬워졌어요.
- **큰 글자 크기** — 글자를 크게 써도 통계·캘린더·루틴 목록·시트가 잘리거나 화면을 넘지 않게 고쳤어요(iPhone·iPad).
- 넘겨받은 템플릿 파일을 여는 과정에서 원본 파일을 건드리지 않도록 했어요.

기존 기록과 iCloud 동기화는 그대로 이어져요.
