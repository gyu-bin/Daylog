## Daylog iOS 1.0.0 (11) — TestFlight "테스트할 내용"

빌드 10 이후 달라진 점입니다. App Store Connect의 "테스트할 내용"에 붙여 넣을 글이에요.

- 새싹이 성장: 루틴을 완료하면 XP가 쌓이고 레벨에 따라 새싹이가 새싹 → 잎사귀 → 꽃으로 자라요("새싹이 성장" 카드).
- "이번 주의 성장" 카드(한 주 목표와 실천한 날), 주간 회고 카드(대시보드 편집에서 켜기), 며칠 쉬고 돌아왔을 때의 "다시 시작하기" 안내와 복귀 알림.
- 오늘 화면 머리말의 새싹이가 인사말과 날짜 단추 사이의 틈 안에서 걷고, 뛰고, 잎을 흔들어요.
- 휴가인 날에는 해먹에서 쉬는 휴가 화면이 나와요(설정 → 휴가에서 미리보기).
- 새 기기의 iCloud 첫 동기화 화면을 기록 받는 중·준비 완료·연결 문제의 움직이는 그림으로 바꿨어요(설정 → iCloud에서 미리보기).

확인해 주시면 좋은 것
- 업데이트 뒤 기존 기록과 XP·레벨이 그대로인지, Mac과 동기화가 이어지는지.
- 머리말 새싹이가 단추나 인사말을 가리지 않는지, 움직임이 버벅이지 않는지.
- 설정 → 손쉬운 사용 → 동작 줄이기를 켰을 때 그림이 멈춰 있는지.
- 휴가 화면·동기화 화면 미리보기가 잘 열리고 닫히는지.
