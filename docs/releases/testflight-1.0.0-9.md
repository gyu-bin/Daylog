## Daylog iOS 1.0.0 (9) — TestFlight "테스트할 내용"

빌드 8 이후 달라진 점입니다. App Store Connect의 "테스트할 내용"에 붙여 넣을 글이에요.

- 오늘 화면의 루틴 줄에 ✓(완료)·»(건너뛰기) 단추가 생겼어요. 체크 칸과 ⋯ 메뉴를 대신해요.
  미완료에서 ✓는 완료, »는 건너뛰기. 완료에서 ✓는 취소, »는 건너뜀으로. 건너뜀에서 »는 취소, ✓는 완료로.
- 건너뜀은 밝은 노랑으로 표시돼요(위젯도 같아요).
- 글자를 크게 쓰는 iPhone에서는 루틴 이름이 윗줄에, 시간과 단추가 아랫줄에 나와요.

확인해 주시면 좋은 것
- iPhone에서 단추를 누르기 편한지, 긴 루틴 이름이 잘리지 않는지.
- 설정 → 손쉬운 사용 → 더 큰 텍스트를 켰을 때 루틴 줄이 잘 보이는지.
- 업데이트 뒤 기존 기록이 그대로인지, Mac과 동기화가 이어지는지.
