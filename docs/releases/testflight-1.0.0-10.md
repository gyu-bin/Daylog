## Daylog iOS 1.0.0 (10) — TestFlight "테스트할 내용"

빌드 9 이후 달라진 점입니다. App Store Connect의 "테스트할 내용"에 붙여 넣을 글이에요.

- 설정 → 정보에 "개인정보 처리방침" 링크가 생겼어요. 누르면 브라우저에서 처리방침 페이지가 열려요.
- 통계 화면의 식사 요약을 화면을 그릴 때마다 바로 읽도록 바꿨어요(보이는 내용은 같아요).

확인해 주시면 좋은 것
- 설정 → 정보 → 개인정보 처리방침을 눌렀을 때 페이지가 잘 열리는지.
- 통계의 식사 기록 일수가 식사 기록 화면과 같은지.
- 업데이트 뒤 기존 기록이 그대로인지, Mac과 동기화가 이어지는지.
