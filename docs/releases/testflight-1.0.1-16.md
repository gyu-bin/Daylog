## TestFlight 1.0.1 (16)

- **피오가 말해요** — 오늘 화면 첫 줄에서 피오가 진행 상황에 맞춰 한마디 해요. 피오를 누르면 다른 말을 하고, 루틴을 체크하면 반응해요. 다른 탭에서는 제목 옆에서 잠깐 인사해요. 설정 맨 위에서 말풍선을 끌 수 있어요.
- **의상 앱 아이콘** — 산 의상의 피오로 홈 화면 아이콘을 바꿀 수 있어요(옷장 → 앱 아이콘).
- **의상 구매** — TestFlight에서는 Sandbox 결제라 실제로 청구되지 않아요.
- **Mac에서 열 때 튕김 수정** — Mac에서 iPad 앱으로 실행하면 시작 직후 종료되던 문제를 고쳤어요.
- 큰 글자 화면 정리, 오늘 화면 피오 자리 정리.
