## Daylog iOS 1.0.0 (7) — TestFlight "테스트할 내용"

빌드 6 이후 달라진 점입니다. App Store Connect의 "테스트할 내용"에 붙여 넣을 글이에요.

- 오늘 건너뛰기: 루틴 줄의 ⋯ → "오늘 건너뛰기". 건너뛴 루틴은 따로 표시되고 알림이 오지 않아요. 위젯에도 반영돼요.
- 통계 → 루틴별 최근 기록(최근 7회).
- 루틴 → [템플릿]: 공식 템플릿 11개 미리보기와 추가.
- 템플릿 파일 공유: [내 루틴 공유하기]로 파일을 만들어 보내고, [파일에서 가져오기]나 파일 앱의 공유 → Daylog로 받아요.
- 오늘 화면 편집: 텍스트 카드·섹션 제목·구분선 추가, 상단 배경 사진.
- 큰 글자 크기(설정 → 손쉬운 사용 → 더 큰 텍스트)에서 통계·캘린더·루틴 목록·시트가 잘리거나 화면을 넘지 않는지 봐 주세요.

확인해 주시면 좋은 것
- 업데이트 뒤 기존 루틴·체크·식사·휴가 기록과 오늘 화면 구성이 그대로인지.
- Mac(1.5.2 또는 1.5.3)과 동기화가 이어지는지. 이전 버전 기기에서는 건너뛴 루틴이 "미완료"로 보여요.
