## Daylog iOS 1.0.0 (8) — TestFlight "테스트할 내용"

빌드 7 이후 달라진 점입니다. App Store Connect의 "테스트할 내용"에 붙여 넣을 글이에요.

- **알림의 [완료]를 누르면 앱이 종료되던 문제를 고쳤어요.** 완료한 뒤 위젯도 바로 바뀌어요.
- 건너뛴 루틴은 회색 "—"와 "건너뜀"으로 표시돼요(줄의 ⋯ → "오늘 건너뛰기").
- [+] 빠른 추가가 휴가인 날이나 오늘 해당하는 항목이 없는 그룹에서도 동작해요(루틴 탭의 그 그룹 입력 칸으로 가요).
- iPad에서 창을 두 개 열었을 때, 한 창에서 편집 중이면 다른 창에서 화면이나 날짜를 옮겨도 편집 창이 닫히지 않아요.
- 설정 → 데이터: [전체 기록 보관용 내보내기]로 이름을 바꿨어요. 지금은 전체 기록을 다시 불러올 수 없어요.

확인해 주시면 좋은 것
- 잠금 화면과 알림 센터에서 알림을 길게 눌러 [완료] → 앱을 열었을 때 완료로 돼 있는지, 홈 화면 위젯이 바뀌었는지.
- 업데이트 뒤 기존 루틴·체크·식사·휴가 기록이 그대로인지, Mac과 동기화가 이어지는지.
