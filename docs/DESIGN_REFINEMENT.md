# Daylog 디자인 정리 (UI/UX Refinement)

시작 커밋: `05dd804` (v1.5.0 배포 직후). 작업은 로컬 `main`에서 바로 한다.

방향: Premium Native · Apple HIG · Modern Colorful Minimal. 기존 Daylog의 정체성(민트 포인트, 파스텔 그룹 색, 둥근 카드, 그림자 없는 평면)은 유지하고, 세부를 고른다.

## 1. 점검에서 찾은 문제

실제 화면(macOS 검증 번들 `com.daylog.verify`, 표본 저장소)을 보고 적었다. 코드만 보고 적은 항목은 "코드"라고 표시했다.

| 화면 | 문제 | 상태 |
|---|---|---|
| 휴가 추가·수정 | 입력 3개에 시트가 500×420 고정이라 아래 절반이 빈다. 날짜는 작은 스테퍼라 기간이 한눈에 안 보인다. 해제 단추가 폼 안에 섞여 있다. | 수정 |
| 휴가 관리 | 520×500 고정 List. 기간이 하나뿐이어도 빈 공간이 크다. | 수정 |
| 휴가 카드(대시보드·캘린더) | 다른 카드와 달리 아이콘 타일이 없고 "기간 추가"가 borderless 단추라 HeaderLink와 다르다. | 수정 |
| 시트 공통 | 루틴 편집은 자체 머리말(제목·닫기·취소·저장), 휴가·가져오기는 Form+toolbar라 틀이 다르다. | 공통 틀(`SheetScaffold`) 도입, 루틴 편집·휴가·휴가 관리 적용 |
| 가져오기·내보내기 | macOS 최소 높이 580 고정, 설명이 길다. | 최소 높이를 내용에 맞춤 |
| 메뉴 막대 아이콘 | 잎사귀+해 조합이 18pt에서 번잡하다. | A안(잎사귀 하나)으로 교체 |
| 메뉴 막대 팝오버 | 머리말·목록·바닥 여백이 10~14pt로 들쭉날쭉. | 여백 정리 |
| 온보딩 | 최소 높이 440 고정, 내용이 짧은 단계에서 아래가 빈다. | 코드 확인, 높이 정리 |

## 2. 공통 디자인 기준

- 색: 바탕·표면은 시스템 색. 포인트는 `Theme.accent`(민트). 의미가 있는 곳에만 색을 쓴다(휴가 = 파랑, 식사 = 코랄, 그룹 = 사용자 색).
- 면: 카드 모서리 14pt(`Theme.cardRadius`), 카드 안 작은 면 9pt(`Theme.controlRadius`). 테두리는 `Theme.cardBorder`(7% 불투명), 그림자 없음.
- 간격: 카드 사이 16pt, 카드 안 18pt, 카드 안 작은 면 안 12pt, 시트 바깥 22pt(`Theme.sheetPadding`).
- 글자: 화면 제목 24pt bold, 시트 제목 title3 semibold, 카드 제목 headline, 보조 설명 caption secondary.
- 시트(macOS): 높이는 내용만큼. 제목+설명 → 내용 → [보조 동작] … [취소] [저장]. Esc 취소, Return 저장. 오른쪽 위 둥근 닫기.
- 시트(iPhone·iPad): 탐색 막대 제목, 왼쪽 취소, 오른쪽 저장, 키보드 위 [완료].
- 파괴적 동작(삭제·해제)은 왼쪽 아래에 떨어뜨려 두고 한 번 더 묻는다.
- 상태: hover는 `Theme.inset`/`Theme.track`, 선택은 포인트 색 14% 바탕 + 테두리, 비활성은 시스템 기본.
- 애니메이션: 0.12~0.25초 easeOut, Reduce Motion이면 없음.

## 3. 휴가·날짜 선택기

- `DayRangeSelection`: 시작일 → 종료일 순서로 고른다. 종료일 차례에 시작일보다 앞선 날을 누르면 시작일이 당겨진다. 종료일이 시작일보다 빠른 상태는 만들 수 없다(테스트 `DesignRefinementTests`).
- `DayRangeCalendar`: 월요일 시작 6줄 고정 격자. 양 끝은 진한 색, 사이는 띠, 오늘은 테두리. macOS에서 방향키로 이동, Return·Space로 선택. VoiceOver에 "10월 14일 수요일, 시작일"처럼 읽힌다. 날짜 연산은 `Day`(UTC 달력)만 써서 시간대 경계 문제가 없다.
- 휴가 시트: 시작일·종료일 칩(누르면 그 날짜를 고치는 차례) + 총 일수 + 달력 + 메모 + 안내. 수정 시 왼쪽 아래 "휴가 해제"(확인창).
