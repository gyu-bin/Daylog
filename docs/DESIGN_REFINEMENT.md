# Daylog 디자인 정리 (UI/UX Refinement)

시작 커밋: `05dd804` (v1.5.0 배포 직후). 작업은 로컬 `main`에서 바로 한다.

방향: Premium Native · Apple HIG · Modern Colorful Minimal. 기존 Daylog의 정체성(민트 포인트, 파스텔 그룹 색, 둥근 카드, 그림자 없는 평면)은 유지하고, 세부를 고른다.

## 1. 점검에서 찾은 문제

실제 화면(macOS 검증 번들 `com.daylog.verify`, 표본 저장소)을 보고 적었다. 코드만 보고 적은 항목은 "코드"라고 표시했다.

## 2. 공통 디자인 기준

- 색: 바탕·표면은 시스템 색. 포인트는 `Theme.accent`(민트). 의미가 있는 곳에만 색을 쓴다(휴가 = 파랑, 식사 = 코랄, 그룹 = 사용자 색).
- 면: 카드 모서리 14pt(`Theme.cardRadius`), 카드 안 작은 면 9pt(`Theme.controlRadius`). 테두리는 `Theme.cardBorder`(7% 불투명), 그림자 없음.
- 간격: 카드 사이 16pt, 카드 안 18pt, 카드 안 작은 면 안 12pt, 시트 바깥 22pt(`Theme.sheetPadding`).
- 글자: 화면 제목 24pt bold, 시트 제목 title3 semibold, 카드 제목 headline, 보조 설명 caption secondary.
- 시트(macOS): 높이는 내용만큼. 제목+설명 → 내용 → [보조 동작] … [취소] [저장]. Esc 취소, Return 저장. 오른쪽 위 둥근 닫기.
- 시트(iPhone·iPad): 탐색 막대 제목, 왼쪽 취소, 오른쪽 저장, 키보드 위 [완료].
- 파괴적 동작(삭제·해제)은 왼쪽 아래에 떨어뜨려 두고 한 번 더 묻는다.
- 상태: hover는 `Theme.inset`/`Theme.track`, 선택은 포인트 색 14% 바탕 + 테두리, 비활성은 시스템 기본.
- 애니메이션: 0.12~0.25초 easeOut, Reduce Motion이면 없음.

## 3. 휴가·날짜 선택기

- `DayRangeSelection`: 시작일 → 종료일 순서로 고른다. 종료일 차례에 시작일보다 앞선 날을 누르면 시작일이 당겨진다. 종료일이 시작일보다 빠른 상태는 만들 수 없다(테스트 `DesignRefinementTests`).
- `DayRangeCalendar`: 월요일 시작 6줄 고정 격자. 양 끝은 진한 색, 사이는 띠, 오늘은 테두리. macOS에서 방향키로 이동, Return·Space로 선택. VoiceOver에 "10월 14일 수요일, 시작일"처럼 읽힌다. 날짜 연산은 `Day`(UTC 달력)만 써서 시간대 경계 문제가 없다.
- 휴가 시트: 시작일·종료일 칩(누르면 그 날짜를 고치는 차례) + 총 일수 + 달력 + 메모 + 안내. 수정 시 왼쪽 아래 "휴가 해제"(확인창).

## 6. 남은 작업

점검은 했지만 이번에 손대지 않은 것(기존 동작이 멀쩡해서 바꾸지 않았다):
- 대시보드 카드 안 여백·그룹 색 활용·드래그 피드백 — 2열 배치 작업에서 정리한 상태 그대로.
- 루틴 관리·식사·통계·캘린더·설정 — 큰 문제 없음. 통계 차트 범례와 설정 긴 설명문은 다음에 줄일 후보.
- iPhone 시트는 `.large` 고정이라 아래가 빈다. 키보드가 올라올 자리를 남긴 것이지만, `.height` 디텐트로 줄이는 것을 검토.
- 가져오기·내보내기 시트를 `SheetScaffold`로 옮기기(지금은 Form+toolbar).
- 애니메이션: 체크·접기·시트 전환은 기존 값 유지. Reduce Motion 처리는 새 달력에도 넣었다.

## 8. 플랫폼별 실제 검증

- macOS(검증 번들, 표본 저장소): 가져오기 미리보기, 설정 전체 스크롤, 휴가 해제 확인창, 라이트. 다크는 1차에서 확인한 시트 틀 그대로라 다시 찍지 않았다.
- iPhone 17 Pro: 휴가 시트 높이·키보드·재열기, 범위 선택.
- iPad Pro 11(iOS 27 시뮬레이터, 세로 전체 화면): 사이드바 2열 대시보드, 휴가 시트가 가운데 폼 시트로 뜸(`vacation-sheet-ipad.png`). 회전·창 조절은 시뮬레이터 도구로 할 수 없어 가로·좁은 창은 미검증.

## 9. 미완료·미검증

- 달력의 방향키·Return 조작과 VoiceOver 실제 읽기(배경에서는 키 입력이 전달되지 않고, VoiceOver는 켜지 않았다). 레이블 문자열은 테스트로만 확인.
- iPad 가로, 창 모드(좁은 창), Split View.
- iPhone 루틴 편집 시트는 내용 높이로 뜨고 삭제 단추까지 보이는 것을 확인했다(`routine-sheet-iphone.png`). 그룹 이름 변경(알림창)과 온보딩 시트는 다시 찍지 않았다.
- 가져오기 "N개 추가…" 확인창과 내보내기 저장 창(파일 패널)은 배경에서 열 수 없어 미검증. 로직은 바꾸지 않았다.
- 메뉴 막대 팝오버 여백(1차와 같음).

| 온보딩 | 2단계 아래 단추를 [나중에 설정하기 / 현재 루틴으로 계속]과 [루틴 만들기]로 나눴다. 어느 쪽이든 3단계(준비 완료)로 간다. 오른쪽 위는 "안내 닫기"(전체 건너뛰기)로 이름을 바꿔 단계 넘기기와 구분했다. iCloud에서 아직 받는 중이면 "지금 만들지 않고 넘어가도 돼요"를 안내한다. 예시 데이터는 만들지 않는다. |

바꾸지 않은 것: 2열 카드 구조와 드래그 편집, 식사 카드(아침·점심·저녁·간식·메모 입력), 최근 7일·내일 할 일 카드, 설정의 항목과 기본값, iPad 설정의 Form 구조(카테고리+상세 패널은 항목 수가 적어 오히려 한 단계가 늘어난다고 보고 두었다).

## 11. 실제 화면 검증

미검증: iPad(이번 변경 화면을 띄우지 않음), 좁은 macOS 창, 신규 사용자(루틴 0개)의 온보딩 "나중에 설정하기" 경로와 iCloud 대기 안내(표본 저장소에는 루틴이 있다 — 단추 이름과 단계 이동은 테스트로 확인), iPhone의 온보딩, ⌘N으로 입력칸이 열리는지.

# 4차: 시안에 가깝게 — 사이드바·휴가 메뉴·대시보드 머리말·설정 2단 (2026-10-12, 기준 커밋 `e050500`)

3차가 "글자 줄이기"에 그쳐 화면이 거의 달라 보이지 않는다는 피드백에 따라, 시안의 눈에 띄는 네 가지를 적용했다.

## 12. 바꾼 것

| 항목 | 변경 |
|---|---|
| 사이드바 | 고르지 않은 메뉴는 회색 선 아이콘, 고른 메뉴만 그 메뉴 색의 채운 아이콘과 진한 글자 + 옅은 색 바탕. 오늘 화면 아이콘을 집에서 격자로. **휴가 메뉴** 추가(통계·캘린더 다음, 설정은 계속 맨 아래 고정). ⌘6 = 휴가, ⌘7 = 설정으로 번호가 하나 밀렸다. |
| 휴가 화면(새로 생김) | 오늘 기준 상태 카드(대시보드와 같은 카드) + 진행 중 / 예정 / 지난 휴가 목록 + [휴가 추가]. 기존 휴가 기록·편집 시트를 그대로 쓴다. iPhone 탭에는 넣지 않았다(탭 다섯 개 유지, 휴가는 오늘 화면의 카드와 설정에서). |
| 대시보드 머리말 | 위에 날짜, 아래에 "오늘도 좋은 하루예요 ☀"(지난 날짜를 보면 "10월 9일의 기록"). 슬로건 줄은 뺐다. 오른쪽은 ‹ › · 오늘 · 편집 · 파란 [+](루틴 빠른 추가, ⌘N과 같다). |
| 휴가 색과 아이콘 | 파랑·해 → 코랄·파라솔. 휴가 중 카드는 코랄 바탕에 제목도 코랄. 달력·히트맵의 휴가 표시도 같은 색. 식사는 코랄 → 주황으로 옮겨 겹치지 않게 했다. |
| 설정 | 넓은 창(macOS·iPad): 왼쪽에 갈래 목록(일반·오늘 화면·루틴·캘린더·알림·휴가·데이터·정보, 색 아이콘 + 한 줄 요약), 오른쪽에 고른 갈래의 설정. iPhone·좁은 창: 갈래 목록 → 눌러서 상세 → 위의 [‹ 설정]으로 복귀. 설정 항목과 값은 그대로이고 위치만 갈래로 나눴다. |

시안과 다르게 둔 것: 메뉴 이름("오늘", "식사 기록")과 메뉴별 색, 식사 카드의 입력칸(시안은 읽기 전용 줄 + 화살표), 계정·언어·효과음 같은 없는 기능.

## 13. 실제 화면 검증

- macOS(검증 번들, 표본 저장소, 라이트): 대시보드 머리말·휴가 중 카드·사이드바(`dashboard-4-after.jpg`), 설정 2단과 갈래 전환(`settings-4-after.jpg`), 휴가 화면(`vacation-screen.jpg`).
- iPhone 17 Pro: 오늘 화면, 설정 갈래 목록(`settings-4-iphone.png`) → 오늘 화면 갈래 → [‹ 설정] 복귀.
- iPad Pro 11(세로): 사이드바(휴가 메뉴 포함)와 대시보드 머리말이 뜨는 것만 확인.

도중에 찾아 고친 문제: iPhone 설정을 `NavigationStack`으로 만들었더니 탭 화면 전체가 하얗게 비었다(iOS 26 시뮬레이터, 원인은 모름). 탐색 스택 없이 목록 ↔ 상세를 직접 바꾸는 방식으로 고쳤다. 뒤로 쓸어넘기기 제스처는 없다.

미검증: 다크 모드의 새 화면들, iPad의 설정 2단·휴가 화면, macOS 좁은 창, 파란 [+]와 ⌘N이 실제로 입력칸을 여는지, ⌘6·⌘7 단축키, 휴가 화면에서의 추가·수정 조작(시트는 기존 것).
