## 설명

설명에는 ✓ 같은 기호를 쓰지 않는다. App Store Connect가 "유효하지 않은 문자"로 거절한다(■와 ·는 받는다).

Daylog는 매일의 루틴을 가볍게 기록하는 앱입니다.
복잡한 설정 없이 오늘 할 일을 체크하고, 쌓인 기록을 통계와 캘린더로 돌아보세요.

■ 오늘의 루틴
· 그룹으로 나눈 루틴을 한 화면에서 확인하고 체크합니다.
· 루틴마다 완료와 건너뛰기 단추가 있어 한 번에 기록합니다.
· 못 하는 날은 건너뛰기로 표시하세요. 건너뛴 루틴은 알림도 오지 않습니다.
· 요일, 시간, 메모를 루틴마다 정할 수 있습니다.

■ 통계와 캘린더
· 기간별 평균 달성률, 달성한 날, 연속 달성 기록을 보여 줍니다.
· 달성률 추이 그래프와 활동 히트맵으로 흐름을 한눈에 봅니다.
· 월간 캘린더에서 날짜별 달성률을 확인하고 지난 기록을 고칩니다.

■ 휴가
· 쉬는 기간을 휴가로 등록하면 그 기간은 통계에서 빠집니다.
· 휴가 중에도 이어 갈 루틴만 골라 둘 수 있습니다.

■ 식사 기록
· 아침·점심·저녁·간식을 간단히 적고, 날짜별로 찾아봅니다.
· 식사 기록은 설정에서 끌 수 있습니다.

■ 오늘 화면 꾸미기
· 카드 순서를 바꾸고 숨기고, 메모 카드와 섹션 제목을 더합니다.
· 상단에 배경 사진을 둘 수 있습니다. 사진은 기기에만 저장됩니다.

■ 템플릿
· 공식 루틴 템플릿을 미리 보고 필요한 것만 추가합니다.
· 내 루틴 구성을 파일로 만들어 주고받을 수 있습니다. 기록은 파일에 들어가지 않습니다.

■ 알림과 위젯
· 루틴 시간에 알림을 받고, 알림에서 바로 완료할 수 있습니다.
· 홈 화면 위젯으로 오늘의 진행 상황을 확인합니다.

■ iCloud 동기화
· iCloud를 켜 두면 같은 Apple 계정의 내 기기에서 같은 기록을 봅니다.
· 기록은 내 기기와 내 iCloud에만 저장됩니다. 회원 가입도, 광고도, 추적도 없습니다.

■ 내보내기
· 루틴 목록을 CSV·JSON으로 내보내고 다시 가져올 수 있습니다.
· 전체 기록을 보관용 파일로 내보낼 수 있습니다(이 버전에서는 전체 기록을 다시 불러오는 기능은 없습니다).

## 앱이 수집하는 데이터 (App Store Connect "앱 개인정보 보호")

**"데이터를 수집하지 않음"** 을 고른다.

- 기록은 기기와 사용자의 개인 iCloud(CloudKit 개인 데이터베이스)에만 저장된다. 개발자는 볼 수 없다.
- 분석 도구, 광고, 추적, 계정 가입이 없다.
- 앱이 스스로 접속하는 곳은 Apple의 iCloud와, 화면 문구·색 같은 표시 설정 파일을 받는 GitHub 한 곳이다. 기록이나 식별자를 보내지 않는다.

## 심사 담당자용 메모

Daylog is a personal routine tracker. No account or sign-in is required and there are no in-app purchases.

How to test
1. Launch the app and finish or close the short onboarding.
2. In the "루틴" tab, add a group and a few routines (or tap "템플릿" and add an official template).
3. In the "오늘" tab, tap ✓ to complete a routine and » to skip it. Progress updates immediately.
4. "통계" shows achievement rates. On iPhone, scroll down in "통계" for the monthly calendar; on iPad, "캘린더" is its own item in the sidebar. "설정" has vacation, notifications, appearance and data export.
5. The privacy policy is linked in "설정" → "정보" → "개인정보 처리방침".

Notes
- Data is stored on the device with SwiftData. If the user is signed in to iCloud, it syncs through the user's private CloudKit database. The app works fully without iCloud.
- Notifications are local only (routine reminders). The permission prompt appears only when the user turns reminders on.
- The app downloads a small JSON file from GitHub Releases that adjusts display strings, accent colour and the default card order. It contains no executable code and does not change app functionality.
- The home screen widget shows today's routines; the large widget can mark a routine done.
- The macOS version is distributed separately outside the App Store.
